# ROLE
Act as a Professional Speechwriter and Pitch Coach specializing in healthcare technology presentations.

# TASK
Write a spoken script for "Speaker One" of a project presentation. 
- **Duration:** Strictly 2 minutes (approximately 250-300 words).
- **Tone:** Professional, confident, persuasive, and engaging.
- **Context:** Use ONLY the information found in the uploaded files/documents. Do not hallucinate data or metrics.

# SCRIPT STRUCTURE & CONTENT REQUIREMENTS
Please follow this exact flow:

1. **Team Introduction (15 seconds):** 
   - Briefly introduce the team. 
   - Use placeholders like [Team Member Name] where specific names are not found in the files.

2. **Problem Origin (30 seconds):** 
   - Explain why this problem exists in the first place.
   - Keep it concise and rooted in the context provided.

3. **Impact & Metrics (45 seconds):** 
   - Detail the actual loss/problem faced by hospitals, clinics, doctors, or patients.
   - **CRITICAL:** Include concrete metrics (US, UK and India data), on how the Readmission problem is in real life hospitals (last 2 years)
   - Cite the source document name for any statistics used. If data is missing, state the qualitative impact instead of inventing numbers.

4. **Use Case Selection (30 seconds):** 
   - Explain why this specific use case was chosen over others.
   - Highlight that team members have real-life experience in similar projects, ensuring deeper understanding and significance.

5. **Market Analysis & Roadmap (30 seconds):** 
   - Summarize the market analysis conducted before choosing the approach.
   - Briefly mention the planning/roadmap created, including any limitations or restrictions considered during planning.

6. **Expected Impact & Transition (30 seconds):** 
   - Conclude with the expected impact of this project on solving the problem.
   - End with a smooth transition phrase (e.g., "Now, let's see how we executed this...") to hand over to the next speaker.

# CONSTRAINTS & RULES
- **Word Count:** Keep the total script to ensure it fits the 3-minute limit.
- **Accuracy:** Do not fabricate statistics. find true specific US/UK/India metrics of last 2 years.
- **Formatting:** Use clear paragraph breaks for each section. Indicate [Pause] or [Emphasis] where appropriate for speech delivery.
- **Context:** Analyze all uploaded files thoroughly before writing to ensure alignment with the project details.

# OUTPUT FORMAT
Provide only the script ready for reading. Do not include extra commentary outside the script.
